4. Relative Color vs. color-mix()

Both techniques create new colors, but they calculate them differently.

Relative Color

Adjusts individual color channels.

oklch(from var(--seed) calc(l + 0.3) c h)

color-mix()

Blends two colors together.

color-mix(in oklch, var(--seed) 30%, white)
